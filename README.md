# Mercado Atlas

Tienda internacional de demostración integrada con el panel CRM del proyecto.

## Publicación en GitHub Pages

Este sitio usa únicamente HTML, CSS y JavaScript estáticos. Para activarlo después de subir los archivos:

1. Abre el repositorio en GitHub y entra en **Settings → Pages**.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Elige la rama `main`, la carpeta `/(root)` y pulsa **Save**.
4. Espera a que GitHub indique que la publicación terminó; la dirección aparecerá en esa misma sección.

GitHub Pages publica el sitio en una dirección pública. El sitio incluye productos ficticios, clientes de demostración, carrito, favoritos y pedidos de prueba. Clientes, carrito y pedidos se guardan en el almacenamiento local de cada navegador; no se comparten entre visitantes. El checkout es de demostración y no procesa pagos. Una base de datos compartida o pagos reales requieren un servicio de servidor aparte.

## Archivos publicados

- `index.html`
- `styles.css` y `store.css`
- `app.js`, `store.js` y `store-data.js`

El PDF del curso y la carpeta `mercado-atlas/` (servidor y dependencias locales) se excluyen de este repositorio de publicación.
